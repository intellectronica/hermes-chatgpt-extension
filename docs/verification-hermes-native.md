## Installed source contracts

- `profiles.list` supplies the profile's configured model/provider and avatar flag. `profiles.get_asset`, scoped to the same profile and name, returns the actual avatar as a bounded data URI. The adapter also probes the default profile when its flag is false. It accepts PNG, JPEG and WebP only, verifies the binary signature, MIME type, base64 and declared size, and returns no protected URLs. Limits are explicit: 100 profiles, 16 avatars, 2 MB per image, 8 MB of combined image data. Installed source: `tui_gateway/methods_profiles.py`.
- `model.options` with `explicit_only:true` and `include_unconfigured:false` supplies the configured profile's available providers and models. IDs encode the provider/model pair, so names shared by providers stay distinct. Unavailable models and unsafe parser tokens are excluded. Only labels and supported capabilities are exposed; provider credentials and endpoint details stay on Hermes. An oversized catalogue fails explicitly rather than dropping the default. Limits are 100 providers and 1,000 model options per profile. Installed sources: `hermes_cli/inventory.py`, `tui_gateway/methods_complete.py`.
- New chats inherit the selected profile's defaults. `config.get` reads effective reasoning, including session overrides. The installed Hermes dial is `none`, `minimal`, `low`, `medium`, `high`, `xhigh`, `max`, `ultra`; the adapter rejects controls explicitly marked unsupported and rejects `none` when reasoning cannot be disabled. The dial does not guarantee that every provider uses every level without clamping. Installed sources: `apps/shared/src/reasoning-effort.ts`, `tui_gateway/methods_config.py`.
- Model changes use `config.set` with the exact owning profile/runtime session, `scope:'session'`, and an explicit `--session` in the model value. A simultaneous reasoning pick is included in the same transaction. Reasoning-only changes also use session scope. The model parser splits whitespace rather than interpreting shell quoting, so selections come from validated catalogue tokens. A guarded model pick returns a confirmation without applying it; a subsequent confirmation must match the same conversation, model and effort. The adapter never auto-confirms. Installed sources: `tui_gateway/methods_config_set.py`, `tui_gateway/model_switch.py`.
- Read-only navigation keeps `session.resume` lazy. Cold ordinary resume can continue interrupted work, and the installed contract offers no per-request `auto_continue:false` equivalent. No prompt is sent by opening, choosing a model or choosing reasoning. Installed sources: `tui_gateway/contracts/sessions.py`, `tui_gateway/methods_session.py`.

## Practical limits

- Accepted selections survive client reconnect while the same Hermes backend owns the runtime session. A backend epoch change clears local acknowledgement pins. The current lazy cold-resume path does not restore all saved runtime model settings, so a fresh private backend can report the current profile defaults. The adapter does not automatically reapply selections or claim durable model pins. Choosing the profile default in an existing conversation applies its current default values explicitly; it is not dynamic inheritance.
- Effective selection comes from session information, accepted setting acknowledgements and config reads. A lazy fallback cannot overwrite a stronger accepted model acknowledgement. If Hermes accepts the model but does not confirm the requested reasoning level, the UI receives an unset effort and an explicit diagnostic rather than the old effort presented as success.
- Guarded confirmation was verified in the contract fixture and actual browser UI. The expensive candidate was cancelled; the profile-default data-policy choice was explicitly confirmed for settings only. No inference was performed. Catalogue membership verifies availability advertised by Hermes, not inference success for every listed model.
- Profile/model metadata is cached for up to 60 seconds and invalidated by RPC connection generation. Actual uploaded images are used directly. The authentic installed Hermes light/dark BrandMark assets provide the UI's small brand fallback; no profile portrait is invented. Installed source: `apps/desktop/src/components/brand-mark.tsx`.
