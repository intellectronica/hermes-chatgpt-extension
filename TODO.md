# First-version checklist

- [ ] Initialise local repository and private HTTPS GitHub remote.
- [ ] Scaffold TypeScript/React project, dependencies and CI.
- [ ] Define shared UI/bridge contracts and supported Hermes protocol.
- [ ] Build installable MCP plugin with UI resource and global/thread entrypoints.
- [ ] Connect to local and remote Hermes with correct authentication.
- [ ] Implement chat history, streaming, tool activity, questions and interruption.
- [ ] Implement profile selection with explicit ownership and independent drafts.
- [ ] Implement read-only cron and run-history views.
- [ ] Verify protocol, security, failure/reconnect and profile-isolation behaviour.
- [ ] Visually verify light/dark and narrow/wide layouts.
- [ ] Verify a real Hermes conversation and profile/cron reads.
- [ ] Verify UI embedded in Codex, or document an exact host blocker while continuing all independent work.
- [ ] Finish setup/usage documentation, push and pass GitHub CI.
